# 界面截图索引

所有图片均来自 Flutter 应用在 Android 模拟器中的实际运行。截图为单独的 PNG 文件，可点击页面名称打开原图。Pixso 原稿参考保存在 [design](design/) 目录，不与运行截图混用。

基准展示尺寸为 375×812 逻辑像素，图片为 750×1624 像素。长页面展示当前滚动位置；服务详情额外提供套餐区截图。
